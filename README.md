# Примеры софта

Два расширения Chrome (Manifest V3), написанных под собственные задачи
в трейдинге на ончейн-рынках. Обе работают поверх gmgn.ai — торгового
терминала, у которого нет публичного API для того, что было нужно.

Кода на ~250 КБ, зависимостей нет ни одной: всё на нативных API браузера.

---

## gmgm_watchlist

Пакетное управление списком отслеживаемых кошельков в GMGN. Отмечаешь
кошельки в таблице холдеров на странице токена — они уходят в вачлист
пачкой, с именами, цветом метки, эмодзи, настройками оповещений и в нужную
группу. Обратный сценарий тоже есть: массовая отписка со страницы `/follow`.

Что здесь интересного с инженерной стороны:

**Авторизация без своих запросов.** У GMGN закрытый API: кроме кук нужен
кастомный заголовок, который выдаётся самой странице. Расширение его не
подделывает и не крадёт — оно перехватывает уже идущие запросы страницы
(`chrome.webRequest`, фильтр строго по `/api/v1/follow/*`, куки из захвата
исключены явно) и переиспользует. Ни одного лишнего обращения к серверу.

**Формы запросов сняты с фронтенда, а не угаданы.** Эндпоинты эмодзи и
оповещений (`remark_wallet_v2` с `operation_type: "emoji"`,
`follow_alert` с плоским телом) вытащены разбором их собственного бандла.
В коде рядом расписано, чем эти формы отличаются от соседних — например
тем, что тройка `[адрес, имя, цвет]` в режиме эмодзи превращается в пару.

**Гонки и идемпотентность.** Кошельки добавляются пачками по 10 параллельно,
но состояние в `chrome.storage` пишется одним read-modify-write на батч —
иначе параллельные записи теряли бы обновления. Повторный клик не дублирует
подписку. Нумерация имён считается от позиции в списке, а не от порядка
ответов сервера, потому что параллельность порядок не гарантирует.

**Экспорт.** Тот же набор адресов уходит и в трекинг-бота — JSON, CSV или
голые адреса, с живым предпросмотром.

Файлы: `gmgn/` — работа с API, `sidebar.*` — панель, `panel.js` —
встраивание панели в страницу, `export.js` — выгрузка.

## angry-tracker-v4

Панель для работы со списками кошельков и сканирования новых токенов.
Держит связь с внешним сервисом трекинга (`trader.bot.nu`) — добавление и
удаление кошельков, анализ источников финансирования, блок-листы.

Из заметного: `shared/sse-client.js` — свой клиент Server-Sent Events с
переподключением; `meme_scanner.js` — сканер новых пар; `bridge.js` —
мост между панелью и вкладками; `ap_channel.js` — обмен между независимыми
контекстами расширения.

## Как посмотреть

```
chrome://extensions → режим разработчика → Загрузить распакованное
```

Указать папку конкретного расширения (не корень репозитория).

---

Код рабочий, используется ежедневно. Внутренние заметки по архитектуре
и истории решений в репозиторий не включены.
